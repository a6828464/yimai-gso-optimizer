# 一麦GSO双擎优化

版本：2.14.1    
作者：一麦瑜伽

一麦瑜伽官网专用的 WordPress AI 内容、SEO 与 GEO 双引擎优化插件。

## 核心流程

1. 安装并启用插件。
2. 在“一麦GSO双擎优化 > 基础设置”配置 AI API。
3. 在“基础设置 > 品牌资料”上传 ZIP 或资料文件。
4. 系统执行隐私硬规则和 AI 分类，管理员复核公开范围。
5. 使用单篇、批量或自动发布生成官网博客。
6. 发布管线继续完成 SEO 元数据、Schema、内链、图片 ALT、Sitemap、llms.txt 和 GEO 检查。
7. 需要时把已发布文章同步进微信公众号草稿箱（只到草稿箱，群发仍由运营到公众号后台手动完成）。

## 公众号同步

v2.10.0 新增「文章 → 微信公众号草稿箱」：已发布文章按公众号约束重排后送进草稿箱，正文图片自动转存、外链转文末脚注、特色图自动裁成 2.35:1 封面。

- 入口：「一麦GSO双擎优化 → 公众号同步」；文章编辑页侧栏也有状态与「立即同步」。
- 挑着同步：同步页的「从历史文章选择同步」可以按关键词/状态筛出任意一篇（已发布 / 草稿 / 待审），点「同步这一篇」即可；草稿被同步不会改变本站的发布状态，公众号侧「阅读原文」留空。
- 凭据：复用「微信分享卡片」页已填的 AppID / AppSecret，不需要重复配置。
- 边界：**只写进草稿箱，不做 freepublish 自动发布，不会推送粉丝**；发布动作在公众号后台人工完成。
- 已知限制：封面读取服务器本地文件，站点启用 OSS/七牛/COS 附件云存储时会失败。
- 运营手册：`docs/公众号同步-使用指南.md`（真机验证清单、失败排查表、手机排版检查）。

## 知识资料边界

- 知识资料在插件安装后导入，不包含在插件源码和发布包中。
- 支持 ZIP、Markdown、TXT、JSON、CSV、DOCX、PDF 和 XLSX。
- 会员身份、体测、病史、员工账号和联系方式默认拦截，不建立文章检索索引。
- 价格合同和内部经营资料默认设为受限，不参与自动生成。
- 健康内容只能用于一般性运动知识和风险提醒，不用于诊断、治疗或效果保证。

## 升级兼容

v2.2.0 继续读取原有 `yimai_gso_` options、文章元数据和数据表。单篇、批量和自动发布统一读取“基础设置 > GEO实体”与“品牌资料”，并对一麦瑜伽品牌边界做强约束。旧 GEO 自动化数据表和字段继续保留兼容，但不再创建独立菜单和 5 分钟队列。

## 运行要求

- WordPress 5.8+
- PHP 7.4+
- MySQL 5.7+ 或 MariaDB 10.3+
- ZIP/DOCX/XLSX 导入建议启用 PHP ZipArchive
- 定时自动发布依赖 WP-Cron；低流量站点建议配置服务器 Cron
