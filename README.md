# 一麦GSO双擎优化

版本：2.2.1  
作者：一麦瑜伽

一麦瑜伽官网专用的 WordPress AI 内容、SEO 与 GEO 双引擎优化插件。

## 核心流程

1. 安装并启用插件。
2. 在“一麦GSO双擎优化 > 基础设置”配置 AI API。
3. 在“基础设置 > 品牌资料”上传 ZIP 或资料文件。
4. 系统执行隐私硬规则和 AI 分类，管理员复核公开范围。
5. 使用单篇、批量或自动发布生成官网博客。
6. 发布管线继续完成 SEO 元数据、Schema、内链、图片 ALT、Sitemap、llms.txt 和 GEO 检查。

## 知识资料边界

- 知识资料在插件安装后导入，不包含在插件源码和发布包中。
- 支持 ZIP、Markdown、TXT、JSON、CSV、DOCX、PDF 和 XLSX。
- 会员身份、体测、病史、员工账号和联系方式默认拦截，不建立文章检索索引。
- 价格合同和内部经营资料默认设为受限，不参与自动生成。
- 健康内容只能用于一般性运动知识和风险提醒，不用于诊断、治疗或效果保证。

## 升级兼容

v2.2.0 继续读取原有 `wpaip_` options、文章元数据和数据表。单篇、批量和自动发布统一读取“基础设置 > GEO实体”与“品牌资料”，并对一麦瑜伽品牌边界做强约束。旧 GEO 自动化数据表和字段继续保留兼容，但不再创建独立菜单和 5 分钟队列。

## 运行要求

- WordPress 5.8+
- PHP 7.4+
- MySQL 5.7+ 或 MariaDB 10.3+
- ZIP/DOCX/XLSX 导入建议启用 PHP ZipArchive
- 定时自动发布依赖 WP-Cron；低流量站点建议配置服务器 Cron
