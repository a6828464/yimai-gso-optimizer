# 微信分享卡片 · 配置与验证指南

> 目标：微信里点「···」→ 发送给朋友 / 分享到朋友圈时，出来的是**带封面图、标题、描述**的卡片，而不是一条裸链接。

## 一、为什么现在只有裸链接

不是 Open Graph 标签没写（站点一直有），而是页面从来没接微信 JS-SDK。

微信内转发网页时，如果没有 JS-SDK，微信只能退回自己的抓取结果；抓不到描述和缩略图就退化成一个 URL。抓得到也只是「标题 + 小图标」的简陋气泡，而且抓取结果还被他缓存几天。

真正能 100% 控制卡片的只有一条路：**服务端签名 + 前端 `wx.config` + `updateAppMessageShareData` / `updateTimelineShareData`**。这就是本模块做的事。

### 三种分享场景，各自靠什么生效

| 场景 | 依赖 | 本模块 |
| --- | --- | --- |
| 微信内打开网页 → 右上角「···」→ 发送给朋友 / 朋友圈 | 微信 JS-SDK | ✅ 完全接管，标题/描述/封面/链接都可控 |
| 在聊天窗口直接粘贴或转发链接 | 微信服务端抓取页面 meta | ✅ 已补齐 `og:image:width/height/type`、`link rel="image_src"`、中文文件名编码 |
| 复制链接发到短信 / QQ / 微博 | 各平台抓取 | ✅ 同上（OG + image_src 通用） |

## 二、前置条件

1. **已认证的服务号或订阅号**（未认证会报 `errcode 48001`，这是硬门槛）。
2. 公众号后台把站点域名加进「JS接口安全域名」。
3. 服务器出口 IP 加进「IP白名单」。

## 三、配置步骤

### 步骤 1：填凭据

后台 → 一麦GSO双擎优化 → **微信分享卡片**：

- AppID：公众号「设置与开发 → 基本配置 → 开发者ID」里的 AppID（`wx` 开头 18 位）
- AppSecret：同页面的 AppSecret（加密存库，只显示后 4 位）

### 步骤 2：公众号校验文件托管

「JS接口安全域名」要求根目录放一个 `MP_verify_xxxxxxxx.txt`，内容是那串 xxxxxxxx。

把这些字符填进面板的「公众号校验文件托管」，插件会直接按地址提供该文件，不用上服务器传：

```
https://www.yimaiyoga.com/MP_verify_xxxxxxxx.txt
```

先在浏览器打开确认返回的就是那串字符，再去公众号后台点保存。

### 步骤 3：公众号后台两处设置

- 设置与开发 → 公众号设置 → 功能设置 → **JS接口安全域名**：填 `www.yimaiyoga.com`（不带 `https://`）
- 设置与开发 → 基本配置 → **IP白名单**：加上服务器出口 IP

### 步骤 4：填分享封面

「分享封面图」挑一张品牌图：JPG/PNG、≥ 500×500、< 300 KB、**文件名用英文**。

文章有特色图时优先用特色图，这张只在没有特色图（以及特色图是 WebP）时兜底。文件名带中文的图片微信抓取器经常取不到，务必重命名。

### 步骤 5：测试

点「测试公众号凭据」：

- 返回 `errcode 40164` → IP 没加白名单，报错信息里带出真实 IP，加进去即可
- 返回 `errcode 40125` / `40001` → AppSecret 错，去后台重置后重填
- 成功 → 拿到 access_token 与 jsapi_ticket

然后打开手机微信，进任意文章页，点右上角「···」→ 发送给朋友，看卡片是否正确。

调试期可以开「调试角标」，页面左下角会显示 `分享卡片已就绪 ✓` 或具体失败原因；确认没问题后关掉。

## 四、验证要点

- 手机微信必须**真机**，PC 微信行为不同，模拟器 UA 也不准
- 分享卡片会按自己的框裁剪缩略图，太长的横图两侧会被切掉，选图时把主体放中间
- 分享标题 ≤ 30 字（微信显示两行），描述 ≤ 70 字（超出省略号），面板里都能调

## 五、真机上没反应怎么查

页面自检全绿、真机还是没卡片，先看后台面板「三、真机诊断」——`wx.config` 的失败原因会由前端回传落到那里。

| 回传的 errMsg | 含义 | 处理 |
| --- | --- | --- |
| `config:invalid signature` | 签名对不上，绝大多数是安全域名和访问域名不一致 | 把 `www.` 和裸域两种写法都加进「JS接口安全域名」 |
| `config:invalid domain` / `invalid url domain` | 访问域名没在安全域名列表里 | 把当前主机名原样加进去 |
| `the permission value is offline verifying` / `48001` | 公众号没有 JS 接口权限 | 完成微信认证；测试号、未认证号都不行 |
| `config:fail` 且没细节 | 签名接口本身挂了 | 回到面板看「最近一次接口错误」与凭据测试结果 |

另外先确认页面自己能打开：

```bash
curl -sS -o /dev/null -w "%{http_code} redirects=%{num_redirects}\n" -L <页面地址>
```

- `200 redirects=0` 才算正常
- `redirects` 二三十跳、最后报 `ERR_TOO_MANY_REDIRECTS` → 404 模块里有一条把 URL 指回它自己的 301 规则。微信抓取器跟到上限就放弃，卡片自然什么都没有。2.9.10 起自指规则会被自动放行，旧规则留着也无害

真机结果也可以在页面上直接看到：开「调试角标」后，微信里页面左下角会把 errMsg 原文贴出来。

## 六、缓存

- **微信内转发**：脚本每次实时取签名，改完设置立刻生效，不用清缓存
- **粘贴到聊天窗口**：微信会缓存抓取结果数小时到数天。改完 meta 后旧链接仍可能显示旧卡片，在链接后面加个参数（`?v=2`）验证新抓取结果
- access_token 与 jsapi_ticket 缓存 7000 秒（微信有效期 7200 秒，留 200 秒余量）；凭据改过之后必须点「清除 token / ticket 缓存」

## 七、抓取被拦的排查（Cloudflare）

站点在 Cloudflare 后面。微信服务端抓取链接时用的是腾讯自己的出口 IP，如果 CF 的 Bot Fight Mode / WAF 把它当机器人挡掉，就会出现「JS-SDK 生效、但粘贴链接仍然没有卡片」。

先确认微信抓取器能进得来：

```bash
curl -s -o /dev/null -w "%{http_code}\n" \
  -A "Mozilla/5.0 (iPhone; CPU iPhone OS 17_0 like Mac OS X) AppleWebKit/605.1.15 (KHTML, like Gecko) Mobile/15E148 MicroMessenger/8.0.49 NetType/WIFI" \
  https://www.yimaiyoga.com/archives/1287
```

- 返回 `200` → 抓取通道正常，问题在别处（多为微信对旧链接的缓存，换 `?v=2` 再试）
- 返回 `403` / `503` / HTML 挑战页 → 到 Cloudflare 控制台加一条 WAF 跳过规则：
  `http.user_agent contains "MicroMessenger"` → Skip → All remaining custom rules / Bot Fight Mode

页面自检面板里的「页面可达」一项也会直接暴露这个问题。

## 八、没有认证公众号时的替代方案

| 方案 | 做法 | 效果 |
| --- | --- | --- |
| 公众号文章 | 把官网文章同步成公众号推文，分享公众号链接 | 原生大卡片，微信最友好 |
| 素材包 | 用朋友圈每日素材站出图 + 文案，手动发 | 图片 + 文案，可控 |
| 只靠抓取 | 本模块的 OG / image_src 部分仍然生效 | 标题 + 小图标气泡，无大图 |

## 九、常见错误码

| errcode | 含义 | 处理 |
| --- | --- | --- |
| 40001 | AppSecret 错 / access_token 被别处刷新失效 | 重新填 AppSecret，清缓存再测 |
| 40013 | AppID 格式不对 | 确认是 `wx` 开头 18 位 |
| 40125 | AppSecret 无效 | 后台重置后重填 |
| 40164 | 出口 IP 不在白名单 | 把报错里的 IP 加进 IP白名单 |
| 48001 | 公众号无此接口权限 | 多为未认证，先完成微信认证 |
| 45009 | 当日调用次数用尽 | 次日恢复；检查是否被刷（模块内置单 IP 每分钟 90 次限流） |

## 十、实现要点（便于后续维护）

- 签名接口：`GET /wp-json/yimai-gso/v1/wechat-jssdk?url=<当前页面>`，只给本站域名签名，返回 `Cache-Control: no-store`，单 IP 每分钟 90 次上限
- 签名算法：`sha1("jsapi_ticket=..&noncestr=..&timestamp=..&url=..")`，参数顺序固定
- iOS 微信校验的是进入页面时的首个 URL，插件在 `<head>` 最前面记录 `window.__ymWxInitUrl`，主题改地址栏也不影响签名
- 分享封面解析顺序：特色图 → 后台封面 → 站点 Logo → 站点图标 → 媒体库最近位图，统一过滤 SVG、把 WebP 降级、非 ASCII 字符转百分号编码
- 关闭模块后前台不输出任何微信脚本，页面行为回到改动前
