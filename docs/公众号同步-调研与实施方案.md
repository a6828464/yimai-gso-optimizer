# WordPress 文章 → 微信公众号 同步发布：调研与实施方案

版本：v1（2026-10-27）
适用：一麦瑜伽官网 WordPress + 一麦GSO双擎优化插件（v2.4.3+）

---

## 0. 一页结论

| 项 | 结论 |
|---|---|
| 能不能做 | 能。微信有正式的「草稿箱 + 发布」开放接口，不是爬虫、不是逆向 |
| 关键前提 | 公众号必须是**已认证**主体。2025 年 7 月起，个人主体、企业未认证主体、不支持认证的账号的发布能力接口已被回收 |
| 落地方式 | **在现有 `yimai-gso-optimizer` 插件里加一个 `class-wechat-publisher.php`**，不新建服务、不引入外部 SaaS |
| 复用资产 | `class-wechat-share.php` 已跑通 `access_token` 获取 + 锁 + 失效自动重试 + 错误码映射，`YIMAI_GSO_Settings` 已存 `wechat_app_id` / `wechat_app_secret`，`docs/` 已能让运维自助配白名单 |
| 最大工作量 | 不是调接口，是**正文改造**：CSS 内联、图片转存、外链处理、代码块。这部分占总工时的 70% |
| 默认策略 | **只进草稿箱，人工复核后发布**。不做全自动发布 |
| 预期必须提前对齐 | 微信 API 只能「发布」，不能「群发」。发布后文章进入公众号历史消息、可通过菜单/转发触达，但**不会主动推送给全部粉丝**。要推给粉丝仍需后台点群发（订阅号 1 次/天，服务号 4 次/月） |
| 工时估算 | 阶段一（可用）2.5 人天；阶段二（健壮）2 人天；阶段三（运营化）2 人天 |

## 1. 现状盘点：我们已经有什么

读了一遍 `yimai-gso-optimizer/` 的源码，这个需求有一半的基建已经躺在仓库里了：

| 已有 | 位置 | 对本需求的价值 |
|---|---|---|
| AppID / AppSecret 存储（加密） | `class-settings.php` → `wechat_app_id` / `wechat_app_secret`，`filter_encrypt_on_save` | 直接读，零改造 |
| access_token 获取 + transient 缓存 + 并发锁 + 被踢重试 | `class-wechat-share.php:564 get_access_token()` | 现成。但方法是 `private`，需要抽成共享 API 类 |
| 微信错误码中文映射（40001/40164/45009/48001） | `class-wechat-share.php:525 wechat_api_error()` | 现成，扩展几个码即可 |
| 后台「微信分享卡片」面板 + 凭据测试 + 自助配置指南 | `class-wechat-share.php` + `docs/微信分享卡片-配置指南.md` | 新模块的设置页可以套同一套 UI 模式 |
| WP-Cron 调度基建 | `class-autopilot-scheduler.php`、`yimai_gso_*_cron` | 异步队列不用另起炉灶 |
| 图片处理能力 | `class-image-handler.php`、`wp_get_image_editor()` | 封面裁切 + 正文图压缩 |
| 文章自动发布管线 | `class-publisher.php`、`class-autopilot-runner.php` | 同步的触发点就挂在这条管线的末端 |

**结论：不需要写一个独立服务，也不需要买第三方同步工具。缺的只是一个"内容改造 + 草稿提交"模块。**

## 2. 开源项目调研

### 2.1 结论先行

GitHub / WordPress 插件市场上，**「公众号 → WordPress」方向有成熟开源项目，「WordPress → 公众号」方向基本只有个人小工具**。原因很简单：正向同步要过微信认证 + IP 白名单 + 内容改造三关，愿意做的人少。

所以这个需求**自研是合理选择**，但可以大量借用现成项目的**内容转换规则**和**API 封装**。

### 2.2 可借用的项目（真实数据，2026-10 核）

#### D 类：反方向（公众号 → WP），说明生态现状

**这个空白就是我们要填的位置，也解释了为什么自研是合理的。**

## 3. 硬约束：微信侧的真实边界

这些约束决定了架构，先列清楚，避免做到一半返工。

### 3.1 权限门槛（一票否决项）

| 约束 | 说明 | 失败表现 |
|---|---|---|
| 主体认证 | 2025-07 起，个人主体 / 企业未认证主体 / 不支持认证的账号，**发布能力接口被回收** | `48001 api unauthorized` |
| IP 白名单 | 调 `cgi-bin/token` 的服务器出口 IP 必须在「开发 → 基本配置 → IP白名单」里 | `40164 invalid ip` |
| 单一 token | 同一 AppID 的 `access_token` **全局唯一**，任何一处刷新都会让别处失效（7200s） | `40001 invalid credential` |
| 调用配额 | 素材 / 草稿接口有每日调用上限，批量同步会撞 | `45009 reach max api daily quota` |

> 我们已经在 `class-wechat-share.php` 里踩过 40164 和 48001，错误码映射和运维文档都现成。

### 3.2 内容格式约束（这是真正的工作量）

| 项目 | 微信的限制 | 我们的对策 |
|---|---|---|
| CSS | **只认内联 `style`**，`class` / `id` / 外部样式表全部被剥掉 | DOM 遍历重写 `style` |
| 图片 | 正文 `<img src>` 必须是微信域（`mmbiz.qpic.cn`），直接引用站外图床会**防盗链不显示** | 先下载 → `/cgi-bin/media/uploadimg` → 替换 src |
| 单图大小 | `uploadimg` 图片 ≤ **1MB**，jpg/png | `wp_get_image_editor()` 压到 900KB 以内、宽 ≤1080 |
| 正文长度 | `content` < **20000 字符** 且 < 1MB | 超长文章自动分篇或截断 + 提示 |
| 标题 | ≤ **64 字** | 取 `post_title`，超长按词截断 |
| 摘要 | ≤ **120 字**；不传则自动取正文前 54 字 | 用 AI 生成的 `excerpt`，超长截断 |
| 封面 | **必须**有 `thumb_media_id`（永久图片素材） | featured image 裁 2.35:1（900×383）→ `material/add_material?type=image` |
| 外链 | 正文里的 `a` 标签指向非微信域时**不可点 / 被提示"不受信任"** | 内链转纯文本；外链转脚注 + 「阅读原文」或自建 H5 中转 |
| 视频 | `<video>` 不支持外链 | 忽略或转视频号卡片 |
| 允许标签 | `section p span img a strong em blockquote ul ol li table tr td h1-h6 code pre` | 其余标签拆包保留文本 |
| 危险属性 | `position:fixed`、`float`、`script`、`iframe`、`form` 会被过滤或破坏布局 | 白名单清理 |

### 3.3 发布 ≠ 群发（必须提前和运营对齐）

| | 群发（mass/sendall） | 发布（freepublish/submit） |
|---|---|---|
| 是否推送给全部粉丝 | 是 | **否**，只进历史消息 |
| 次数限制 | 订阅号 1 次/天，服务号 4 次/月 | 不占群发次数，有每日上限 |
| 是否能走 API | 图文群发已不对外开放 | 是，`/cgi-bin/freepublish/submit` |

**所以"同步发布"的准确效果是：文章出现在公众号里、有永久链接、能通过菜单/自动回复/转发触达，但不会主动弹到粉丝的手机上。** 如果运营的预期是"发完 WP 粉丝就收到推送"，那预期需要当场修正——这件事只能靠后台手工群发。

## 4. 三条技术路线对比

| | 方案 A：插件内直连 | 方案 B：插件 + 独立中控服务 | 方案 C：浏览器插件（Wechatsync） |
|---|---|---|---|
| 形态 | `publish` hook → WP-Cron 队列 → 微信 API | WP 插件 POST → 云主机 worker → 微信 API | 人工在浏览器点一下 |
| 开发量 | 小（2.5 人天） | 中（6-8 人天） | 0 |
| 自动化 | 全自动 | 全自动 | 半自动，需人工 |
| 长任务风险 | PHP 超时（多图上传 10-30s），但可用 cron 分批 | 无 | 无 |
| token 冲突 | 需与 `wechat-share` 共用管理器（已有锁） | 天然无冲突 | 不涉及 token |
| 动态 IP 影响 | 有（40164） | 无（中控固定 IP） | 无（走后台登录态） |
| 需要认证主体 | 是 | 是 | **否** |
| 适合 | **我们** | 多站点 / 高并发 | 先验证效果 / 应急 |

### 推荐：**A 为主线，C 为验证手段**

理由：
1. 站点已有可用 token 链路（jsapi 已通说明认证和白名单都过了），方案 A 的前置条件已满足
2. 插件已有 cron 和队列基建，不需要新增部署单元
3. 单站、日更 1-3 篇的量级，方案 B 的复杂度是浪费
4. 但**先用 C 花半天跑一遍**，把排版问题暴露在写代码之前——这是最省时间的一步

如果后续要扩到多站点（比如一麦 + 其他品牌站共用同一公众号），再把内容改造模块抽成中控服务，即方案 B。

## 6. 内容流水线（核心，逐条可执行）

`YIMAI_GSO_Wx_Renderer::render( $post_id )` 的 10 步：

1. **取源**：`apply_filters( 'the_content', $post->post_content )`，得到渲染后的 HTML。**不要**用 `post_content` 原文（Gutenberg 区块注释会污染）。
2. **剥壳**：去掉 `script / style / iframe / form / input / button / noscript / svg`。
3. **白名单化**：只保留 `section p span img a strong em b i blockquote ul ol li table thead tbody tr th td h1-h6 code pre br hr figure figcaption`，其余标签用 `unwrap()`（保留子节点，丢标签）。
4. **清属性**：删 `class / id / data-* / on*`，保留 `src / href / alt / colspan / rowspan`。
5. **样式内联**：按 tag 查 `STYLE_MAP` 写入 `style`，已有 `style` 的做合并（我们的样式优先级更高，但保留 `text-align`、`color` 这类作者意图）。
6. **图片流水线**：逐张 `download → wp_get_image_editor → resize(1080) → save(jpeg, 82) → 体积检测 ≤900KB → uploadimg → 替换 src → 补 style="max-width:100%;height:auto;display:block;margin:16px auto"`。任何一张失败：**替换为占位说明文字**，不让整篇失败。
7. **链接处理**：`a[href]` 主机名在本站 → 转 `<span style="color:#576b95">`（保留视觉提示）；外链 → 转 `<span>` + 文末脚注列表（或替换成配置的 H5 中转前缀）。
8. **代码块**：`pre` 内容做 HTML 转义（`&lt;`），包一层 `<section style="background:#f6f8fa;padding:14px 16px;border-radius:6px;overflow-x:auto;font-size:13px;line-height:1.7">`；`code` 用 `font-family:Menlo,Consolas,monospace;white-space:pre`。
9. **表格**：`table` 加 `width:100%;border-collapse:collapse;font-size:14px`，`th/td` 加 `border:1px solid #e5e6eb;padding:8px 10px`。
10. **整体包裹**：`<section style="font-size:16px;line-height:1.75;color:#3f3f3f;letter-spacing:0.5px;word-break:break-word">…</section>`。
11. **校验**：`mb_strlen(content) < 20000`、`strlen(content) < 1048576`；标题 ≤64 字；摘要 ≤120 字。超限抛 `WP_Error` 进 `failed` 状态并给出人话提示。

## 7. 数据模型

### 7.1 队列表 `{prefix}yimai_gso_wx_jobs`

```sql
CREATE TABLE {prefix}yimai_gso_wx_jobs (
  id            BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  post_id       BIGINT UNSIGNED NOT NULL,
  content_hash  CHAR(32) NOT NULL,            -- md5(title+content+cover)
  state         VARCHAR(16) NOT NULL DEFAULT 'pending',
  attempts      SMALLINT UNSIGNED DEFAULT 0,
  next_run_at   DATETIME NOT NULL,
  wx_media_id   VARCHAR(128) DEFAULT NULL,    -- 草稿 media_id
  wx_publish_id VARCHAR(128) DEFAULT NULL,    -- 发布任务 id
  wx_thumb_id   VARCHAR(128) DEFAULT NULL,    -- 封面永久素材 id
  article_url   VARCHAR(255) DEFAULT NULL,    -- 发布后的永久链接
  error_code    INT DEFAULT NULL,
  error_msg     TEXT,
  payload       LONGTEXT,                     -- 调试用，脱敏后可回溯
  created_at    DATETIME NOT NULL,
  updated_at    DATETIME NOT NULL,
  UNIQUE KEY uniq_post_hash (post_id, content_hash),
  KEY idx_state_run (state, next_run_at)
) {charset_collate};
```

### 7.2 文章元数据（便于编辑页展示，不重复查表）

| meta key | 值 |
|---|---|
| `_yimai_wx_state` | `pending / drafted / published / failed / skipped` |
| `_yimai_wx_media_id` | 草稿 media_id |
| `_yimai_wx_article_url` | 发布后链接 |
| `_yimai_wx_synced_at` | 时间戳 |
| `_yimai_wx_optout` | `1` = 这篇文章不同步 |

### 7.3 幂等规则

- 同一 `post_id` + 同一 `content_hash` → **不新建**，直接复用已有 `wx_media_id`
- 内容变了（`content_hash` 变）→ 若已有 `media_id` 走 **`draft/update`** 覆盖，否则 `draft/add`
- 已 `published` 的文章改内容 → **不自动改线上文章**，只把状态标为 `outdated`，让运营决定是否重新发布

## 8. 代码骨架

### 8.1 第一步：抽出共享 API 类（半天）

`class-wechat-share.php` 里的 `get_access_token()` 是 `private`。新建 `includes/class-wechat-api.php`：

```php
<?php
if ( ! defined( 'ABSPATH' ) ) exit;

/**
 * 公众号服务端 API 共享封装。
 * token 缓存/锁/失效重试从 Wechat_Share 迁入，两处共用同一份，避免互踢。
 */
class YIMAI_GSO_Wx_Api {

    const TOKEN_TRANSIENT = 'yimai_gso_wx_access_token';
    const LOCK_TRANSIENT  = 'yimai_gso_wx_token_lock';
    const CACHE_TTL       = 7000;

    public static function get_access_token( $force = false ) {
        if ( ! $force ) {
            $cached = get_transient( self::TOKEN_TRANSIENT );
            if ( is_string( $cached ) && '' !== $cached ) return $cached;
            if ( get_transient( self::LOCK_TRANSIENT ) ) {
                for ( $i = 0; $i < 6; $i++ ) {
                    usleep( 250000 );
                    $cached = get_transient( self::TOKEN_TRANSIENT );
                    if ( is_string( $cached ) && '' !== $cached ) return $cached;
                }
            }
        }
        $app_id = trim( (string) YIMAI_GSO_Settings::get( 'wechat_app_id', '' ) );
        $secret = trim( (string) YIMAI_GSO_Settings::get( 'wechat_app_secret', '' ) );
        if ( '' === $app_id || '' === $secret ) {
            return new WP_Error( 'wx_unconfigured', '未填写公众号 AppID / AppSecret' );
        }
        set_transient( self::LOCK_TRANSIENT, 1, 15 );
        $res = wp_remote_get( add_query_arg(
            array( 'grant_type' => 'client_credential', 'appid' => $app_id, 'secret' => $secret ),
            'https://api.weixin.qq.com/cgi-bin/token'
        ), array( 'timeout' => 15 ) );
        delete_transient( self::LOCK_TRANSIENT );
        if ( is_wp_error( $res ) ) return $res;
        $data = json_decode( wp_remote_retrieve_body( $res ), true );
        if ( empty( $data['access_token'] ) ) {
            return new WP_Error( 'wx_token', self::explain( $data ), $data );
        }
        $ttl = isset( $data['expires_in'] ) ? (int) $data['expires_in'] : 7200;
        set_transient( self::TOKEN_TRANSIENT, (string) $data['access_token'], max( 120, min( self::CACHE_TTL, $ttl - 200 ) ) );
        return (string) $data['access_token'];
    }

    /** 统一 JSON POST，token 失效自动重试一次 */
    public static function post( $path, array $body, $retry = 1 ) {
        $token = self::get_access_token();
        if ( is_wp_error( $token ) ) return $token;
        $res = wp_remote_post(
            'https://api.weixin.qq.com' . $path . '?access_token=' . rawurlencode( $token ),
            array(
                'timeout' => 30,
                'headers' => array( 'Content-Type' => 'application/json; charset=utf-8' ),
                'body'    => wp_json_encode( $body, JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES ),
            )
        );
        if ( is_wp_error( $res ) ) return $res;
        $data = json_decode( wp_remote_retrieve_body( $res ), true );
        $code = isset( $data['errcode'] ) ? (int) $data['errcode'] : 0;
        if ( in_array( $code, array( 40001, 42001, 40014 ), true ) && $retry > 0 ) {
            self::get_access_token( true );
            return self::post( $path, $body, $retry - 1 );
        }
        if ( 0 !== $code ) return new WP_Error( 'wx_api_' . $code, self::explain( $data ), $data );
        return $data;
    }

    /** 图片上传：走 uploadimg，不允许外链占位 */
    public static function upload_content_image( $binary, $filename = 'img.jpg' ) {
        $token = self::get_access_token();
        if ( is_wp_error( $token ) ) return $token;
        $boundary = wp_generate_password( 24, false );
        $body  = "--{$boundary}\r\n";
        $body .= "Content-Disposition: form-data; name=\"media\"; filename=\"{$filename}\"\r\n";
        $body .= "Content-Type: application/octet-stream\r\n\r\n{$binary}\r\n";
        $body .= "--{$boundary}--\r\n";
        $res = wp_remote_post(
            'https://api.weixin.qq.com/cgi-bin/media/uploadimg?access_token=' . rawurlencode( $token ),
            array(
                'timeout' => 45,
                'headers' => array( 'Content-Type' => 'multipart/form-data; boundary=' . $boundary ),
                'body'    => $body,
            )
        );
        if ( is_wp_error( $res ) ) return $res;
        $data = json_decode( wp_remote_retrieve_body( $res ), true );
        if ( ! empty( $data['errcode'] ) ) return new WP_Error( 'wx_uploadimg_' . $data['errcode'], self::explain( $data ), $data );
        return isset( $data['url'] ) ? $data['url'] : new WP_Error( 'wx_uploadimg', '未返回图片 URL', $data );
    }

    /** 封面：永久图片素材，返回 media_id */
    public static function upload_permanent_image( $binary, $filename = 'cover.jpg' ) {
        $token = self::get_access_token();
        if ( is_wp_error( $token ) ) return $token;
        $boundary = wp_generate_password( 24, false );
        $body  = "--{$boundary}\r\n";
        $body .= "Content-Disposition: form-data; name=\"media\"; filename=\"{$filename}\"\r\n";
        $body .= "Content-Type: image/jpeg\r\n\r\n{$binary}\r\n";
        $body .= "--{$boundary}--\r\n";
        $res = wp_remote_post(
            'https://api.weixin.qq.com/cgi-bin/material/add_material?access_token=' . rawurlencode( $token ) . '&type=image',
            array(
                'timeout' => 45,
                'headers' => array( 'Content-Type' => 'multipart/form-data; boundary=' . $boundary ),
                'body'    => $body,
            )
        );
        if ( is_wp_error( $res ) ) return $res;
        $data = json_decode( wp_remote_retrieve_body( $res ), true );
        if ( ! empty( $data['errcode'] ) ) return new WP_Error( 'wx_material_' . $data['errcode'], self::explain( $data ), $data );
        return isset( $data['media_id'] ) ? $data['media_id'] : new WP_Error( 'wx_material', '未返回 media_id', $data );
    }

    public static function create_draft( array $article ) {
        return self::post( '/cgi-bin/draft/add', array( 'articles' => array( $article ) ) );
    }

    public static function update_draft( $media_id, $index, array $article ) {
        return self::post( '/cgi-bin/draft/update', array(
            'media_id' => $media_id,
            'index'    => (int) $index,

        ) );
    }

    public static function get_draft( $media_id ) {
        return self::post( '/cgi-bin/draft/get', array( 'media_id' => $media_id ) );
    }

    public static function submit_publish( $media_id ) {

    }

    public static function get_publish_status( $publish_id ) {
        return self::post( '/cgi-bin/freepublish/get', array( 'publish_id' => $publish_id ) );
    }

    /** 错误码 → 人话；沿用 wechat-share 的映射并补齐草稿/发布相关码 */
    public static function explain( $data ) {
        $map = array(
            40001 => 'AppSecret 不正确，或 access_token 已被别处刷新失效',
            40007 => 'media_id 无效（草稿可能已被删除）',
            40009 => '图片大小超限（uploadimg 单图 ≤ 1MB）',
            40164 => '服务器出口 IP 不在公众号 IP 白名单内',
            45009 => '接口调用次数已达当日上限',
            45028 => '素材数量已达上限，请先在后台清理',
            48001 => '该公众号未获得此接口权限（需已认证主体）',
            53503 => '正文内容超长或含不支持的结构',
        );
        $code = isset( $data['errcode'] ) ? (int) $data['errcode'] : 0;
        $msg  = isset( $data['errmsg'] ) ? (string) $data['errmsg'] : '';
        $text = isset( $map[ $code ] ) ? $map[ $code ] : ( '' !== $msg ? $msg : '未知微信接口错误' );
        if ( 40164 === $code && preg_match( '/(\d{1,3}(?:\.\d{1,3}){3})/', $msg, $m ) ) {
            $text .= '（检测到真实出口 IP：' . $m[1] . '）';
        }
        return $text . ' [' . $code . ']';
    }
}
```

```php
<?php
if ( ! defined( 'ABSPATH' ) ) exit;

class YIMAI_GSO_Wechat_Publisher {

    const CRON_HOOK = 'yimai_gso_wx_sync_cron';
    const TABLE     = 'yimai_gso_wx_jobs';

    public static function init() {
        add_action( 'transition_post_status', array( __CLASS__, 'on_publish' ), 20, 3 );
        add_action( 'yimai_gso_after_publish', array( __CLASS__, 'on_pipeline_publish' ), 20, 1 );
        add_action( self::CRON_HOOK, array( __CLASS__, 'run_queue' ) );
        add_action( 'init', array( __CLASS__, 'ensure_schedule' ) );
    }

    public static function on_publish( $new, $old, $post ) {
        if ( 'publish' !== $new || 'post' !== $post->post_type ) return;
        if ( 'publish' === $old ) return;                       // 更新不重复触发
        if ( get_post_meta( $post->ID, '_yimai_wx_optout', true ) ) return;
        if ( ! YIMAI_GSO_Settings::get( 'wx_sync_enabled', 0 ) ) return;
        if ( ! self::match_rules( $post ) ) return;             // 分类/作者白名单
        self::enqueue( $post->ID );
    }

    public static function enqueue( $post_id ) {
        global $wpdb;
        $hash = self::content_hash( $post_id );
        $now  = current_time( 'mysql', true );
        $wpdb->query( $wpdb->prepare(
            "INSERT IGNORE INTO {$wpdb->prefix}" . self::TABLE . "
             (post_id, content_hash, state, attempts, next_run_at, created_at, updated_at)
             VALUES (%d, %s, 'pending', 0, %s, %s, %s)",
            $post_id, $hash, $now, $now, $now
        ) );
        update_post_meta( $post_id, '_yimai_wx_state', 'pending' );
    }

    public static function run_queue() {
        global $wpdb;
        $rows = $wpdb->get_results(
            "SELECT * FROM {$wpdb->prefix}" . self::TABLE . "
             WHERE state IN ('pending','failed') AND next_run_at <= UTC_TIMESTAMP()
             ORDER BY next_run_at ASC LIMIT 3"
        );
        foreach ( $rows as $row ) {
            $wpdb->update( "{$wpdb->prefix}" . self::TABLE,
                array( 'state' => 'processing', 'updated_at' => current_time( 'mysql', true ) ),
                array( 'id' => $row->id )
            );
            $result = self::process( $row );
            if ( is_wp_error( $result ) ) {
                self::fail( $row, $result );
            } else {
                $wpdb->update( "{$wpdb->prefix}" . self::TABLE, array_merge(
                    array( 'state' => 'drafted', 'updated_at' => current_time( 'mysql', true ), 'error_code' => null, 'error_msg' => null ),
                    $result
                ), array( 'id' => $row->id ) );
                update_post_meta( $row->post_id, '_yimai_wx_state', 'drafted' );
            }
        }
    }

    /** 单篇完整处理：渲染 → 封面 → 草稿（或更新草稿） */
    private static function process( $row ) {
        $post = get_post( $row->post_id );
        if ( ! $post || 'publish' !== $post->post_status ) {
            return new WP_Error( 'wx_skip', '文章不存在或已下线' );
        }
        $content  = YIMAI_GSO_Wx_Renderer::render( $post );
        if ( is_wp_error( $content ) ) return $content;

        $thumb_id = self::ensure_cover( $post );
        if ( is_wp_error( $thumb_id ) ) return $thumb_id;

        $article = array(
            'title'                 => self::trim_title( $post->post_title ),
            'author'                => YIMAI_GSO_Settings::get( 'wx_default_author', '一麦瑜伽' ),
            'digest'                => self::trim_digest( $post ),
            'content'               => $content,
            'content_source_url'    => get_permalink( $post ),
            'thumb_media_id'        => $thumb_id,
            'need_open_comment'     => 0,
            'only_fans_can_comment' => 0,
        );

        if ( ! empty( $row->wx_media_id ) ) {
            YIMAI_GSO_Wx_Api::update_draft( $row->wx_media_id, 0, $article );
            return array( 'wx_thumb_id' => $thumb_id );
        }
        $res = YIMAI_GSO_Wx_Api::create_draft( $article );
        if ( is_wp_error( $res ) ) return $res;
        return array(
            'wx_media_id' => $res['media_id'],
            'wx_thumb_id' => $thumb_id,
        );
    }

    /** 封面：featured image → 裁 2.35:1 → 压 900KB → 永久素材 */
    private static function ensure_cover( $post ) {
        $thumb_id = get_post_thumbnail_id( $post->ID );
        if ( ! $thumb_id && (int) YIMAI_GSO_Settings::get( 'wx_cover_fallback_id', 0 ) ) {
            $thumb_id = (int) YIMAI_GSO_Settings::get( 'wx_cover_fallback_id', 0 );
        }
        if ( ! $thumb_id ) return new WP_Error( 'wx_no_cover', '缺少封面图，请在文章设置特色图片' );

        $path = get_attached_file( $thumb_id );
        if ( ! $path || ! file_exists( $path ) ) return new WP_Error( 'wx_cover_missing', '封面文件不存在' );

        $editor = wp_get_image_editor( $path );
        if ( is_wp_error( $editor ) ) return $editor;
        $editor->resize( 900, 383, true );
        $editor->set_quality( 82 );
        $tmp = wp_tempnam( 'wx-cover' );
        $saved = $editor->save( $tmp, 'image/jpeg' );
        if ( is_wp_error( $saved ) ) return $saved;
        $binary = file_get_contents( $saved['path'] );
        @unlink( $saved['path'] );
        if ( strlen( $binary ) > 10 * 1024 * 1024 ) {
            return new WP_Error( 'wx_cover_big', '封面超过 10MB' );
        }
        return YIMAI_GSO_Wx_Api::upload_permanent_image( $binary, 'cover.jpg' );
    }

    private static function fail( $row, $error ) {
        global $wpdb;
        $attempts = (int) $row->attempts + 1;
        $delay    = min( 3600, 60 * (int) pow( 5, min( $attempts - 1, 4 ) ) );  // 1m/5m/25m/1h
        $state    = $attempts >= 5 ? 'dead' : 'failed';
        $wpdb->update( "{$wpdb->prefix}" . self::TABLE, array(
            'state'       => $state,
            'attempts'    => $attempts,
            'next_run_at' => gmdate( 'Y-m-d H:i:s', time() + $delay ),
            'error_code'  => isset( $error->error_data['data']['errcode'] ) ? (int) $error->error_data['data']['errcode'] : null,
            'error_msg'   => $error->get_error_message(),
            'updated_at'  => current_time( 'mysql', true ),
        ), array( 'id' => $row->id ) );
        update_post_meta( $row->post_id, '_yimai_wx_state', 'failed' );
    }

    private static function content_hash( $post_id ) {
        $post = get_post( $post_id );
        return md5( $post->post_title . '|' . $post->post_modified_gmt . '|' . get_post_thumbnail_id( $post_id ) );
    }

    private static function trim_title( $t ) {
        $t = wp_strip_all_tags( $t );
        return mb_strlen( $t ) > 64 ? mb_substr( $t, 0, 62 ) . '…' : $t;
    }

    private static function trim_digest( $post ) {
        $d = has_excerpt( $post ) ? get_the_excerpt( $post ) : '';
        if ( '' === $d ) {
            $d = mb_substr( wp_strip_all_tags( do_shortcode( $post->post_content ) ), 0, 110 );
        }
        $d = trim( preg_replace( '/\s+/u', ' ', wp_strip_all_tags( $d ) ) );
        return mb_strlen( $d ) > 120 ? mb_substr( $d, 0, 118 ) . '…' : $d;
    }

    public static function ensure_schedule() {
        if ( ! wp_next_scheduled( self::CRON_HOOK ) ) {
            // 复用 class-autopilot-scheduler.php 已注册的间隔，不重复注册 cron_schedules
            wp_schedule_event( time() + 60, 'yimai_gso_every_five_minutes', self::CRON_HOOK );
        }
    }

    private static function match_rules( $post ) {
        $cats = (array) YIMAI_GSO_Settings::get( 'wx_sync_categories', array() );
        if ( empty( $cats ) ) return true;
        return (bool) array_intersect( wp_get_post_categories( $post->ID ), array_map( 'intval', $cats ) );
    }
}
```

| 3.2 | 批量补同步：按日期/分类筛历史文章，批量入队（限速 1 篇/分钟避 45009） | 0.5d |
| 3.3 | 数据回流：阅读数/在看数拉回 WP，做内容效果看板 | 0.5d |
| 3.4 | 多公众号支持：设置里存多套 appid/secret，文章级选择目标号 | 0.5d |

### 关键路径与前置

```
[0] 确认公众号主体已认证 + AppID/AppSecret 可用 + 当前出口 IP 在白名单   ← 一天内必须确认，否则全盘停
      ↓
[1] 半天：用 Wechatsync 跑通一次，出「排版差异清单」
      ↓
[2] 阶段一 → [3] 阶段二 → 上线（默认只进草稿箱）
      ↓
[4] 运营跑两周，看草稿使用率 → 决定是否做阶段三的「一键发布」
```

**总工期：5.5 人天（阶段一+二），加上验证和调试缓冲，排 7 个工作日。**

## 10. 风险与对策

| 风险 | 概率 | 影响 | 对策 |
|---|---|---|---|
| 公众号未认证 → 全部接口 48001 | 中 | 致命 | **第 0 天先验证**。未认证只能走 Wechatsync 人工方案 |
| 站点出口 IP 漂移（家宽） → 40164 | 中高 | 同步全挂 | ①站点固定在云主机；②或加一层 CF Workers 中控（[wechat-mp-push](https://github.com/vigez/wechat-mp-push) 的思路），把 CF 出口段加入白名单 |
| `wechat-share` 和新模块抢 token | 高（若不抽公共类） | 随机 40001 | 阶段一 1.1 必须先做，两处共用一个 transient + lock |
| 图片转存慢导致 PHP 超时 | 高 | 部分失败 | 队列单篇处理 + `set_time_limit(120)` + 单篇图片数上限 20 张，超出的保留外链并标记 |
| 排版在手机上崩 | 高 | 体验差 | 阶段一必须做「渲染预览」；上线前用 3 种机型验收（iOS 微信 / 安卓微信 / 微信 PC） |
| 45009 配额用尽 | 中 | 当日停摆 | 批量任务限速 + 每日调度上限 + 配额接近时后台告警（复用 `class-alert-engine.php`） |
| 运营误以为"发 WP 就推给粉丝" | 高 | 预期落差 | 设置页显式写明「同步只进草稿箱，推送需后台群发」，并在首次使用时弹一次说明 |
| 微信接口变更 | 低 | 需改代码 | 错误码映射已覆盖；`explain()` 会把未知码原样暴露，便于排查 |

## 11. 验收清单

上线前逐条打勾：

**权限**
- [ ] `cgi-bin/token` 返回 200，无 40164
- [ ] `draft/add` 返回 `media_id`（说明草稿权限在）
- [ ] `freepublish/submit` 不返回 48001（说明发布权限在，阶段三用）

**内容**
- [ ] 纯文字文章 → 草稿段落间距、行高与设计稿一致
- [ ] 多图文章 → 全部图片显示，无裂图、无防盗链空白
- [ ] 含表格文章 → 表格边框完整、不溢出屏幕
- [ ] 含代码块文章 → 等宽字体、可横向滚动、`<` `>` 正确转义
- [ ] 含外链文章 → 链接不可点但文字保留，文末有脚注
- [ ] 20000 字以上文章 → 明确报错提示，不是静默失败
- [ ] 无封面文章 → 用兜底封面，不报错

**健壮性**
- [ ] 断网重试 3 次后恢复
- [ ] 同一篇连点 5 次「同步」 → 只产生 1 个草稿
- [ ] 改标题后重新同步 → 草稿被更新而非新增
- [ ] 手动清除 transient 模拟 token 失效 → 自动恢复
- [ ] 队列积压 10 篇 → 5 分钟内消化完，无 45009

**运营可用**
- [ ] 编辑页能看到同步状态、错误原因、微信侧预览入口
- [ ] 能对单篇「不同步」打标记
- [ ] 设置页有完整说明，非技术人员能自助排查 40164/48001

## 12. 附：错误码速查（扩展版）

| errcode | 含义 | 处理 |
|---|---|---|
| 40001 | AppSecret 错 / token 被别处刷新 | 检查密钥；清 token 缓存；确认没有第三个系统共用 AppID |
| 40007 | media_id 无效 | 草稿被后台删除，重新 `draft/add` |
| 40009 | 图片超限 | `uploadimg` 单图 ≤ 1MB，检查压缩链路 |
| 40164 | IP 不在白名单 | 报错信息里带真实 IP，加进「基本配置 → IP白名单」 |
| 42001 | token 过期 | 自动刷新（已有重试） |
| 45009 | 当日调用上限 | 降速 + 次日重试 |
| 45028 | 素材数量达上限 | 后台清理永久素材 |
| 48001 | 无接口权限 | 主体未认证，一票否决 |
| 53503 | 正文结构不支持 | 查是否有非法标签/属性残留 |
