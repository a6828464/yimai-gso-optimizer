# 一麦GSO双擎优化使用教程

## 安装

1. 在 WordPress 后台上传 `yimai-gso-optimizer-v2.4.0.zip`。
2. 启用“一麦GSO双擎优化”。
3. 进入“一麦GSO双擎优化 > 基础设置”，配置 AI 平台、模型和 API Key。
4. 在“GEO实体”填写品牌主体信息，在“品牌资料”导入课程、服务和公开内容资料。

## 导入一麦资料

1. 打开“一麦GSO双擎优化 > 基础设置 > 品牌资料”。
2. 上传知识库 ZIP，或选择多个 Markdown、TXT、JSON、CSV、DOCX、PDF、XLSX 文件。
3. 等待本地解析和 AI 分类。
4. 查看资料范围：公开、内部参考、受限或已拦截。
5. 管理员复核后再将适合官网使用的资料设为“公开”。

已拦截资料只保留必要的识别记录，不保存正文，也不会参与文章生成。内部参考资料可帮助模型理解一麦业务，但提示词会明确禁止逐字公开。

## 自动更新博客

1. 打开“内容创作 > 自动发布”。
2. 设定每天运行时间、文章数量、分类、篇幅、配图数量和发布状态。
3. 可填写人工主题列表；留空时，系统会从已批准知识资料中选取主题种子。
4. 初次运行建议选择“草稿”，人工检查品牌事实、健康边界和排版。
5. 稳定后再切换为定时发布或直接发布。

## SEO 与 GEO

文章发布后可继续使用：

- SEO 标题、摘要、关键词和 canonical。
- H1-H3 结构、内链、图片 ALT 和内容新鲜度。
- Article、FAQ、Breadcrumb、LocalBusiness 等 Schema。
- Sitemap、llms.txt 和搜索引擎推送。
- GEO 可提取性、实体一致性、FAQ、引用与品牌可见度扫描。

GEO 扫描属于模型模拟结果，不等同于搜索平台的真实排名。新版扫描使用不带品牌暗示的中性问题，再检测回答是否自然提及一麦。

## 安全边界

- 不要把会员身份、联系方式、体测、病史或私聊资料调整为公开。
- 孕产、疼痛、麻木、康复和药物内容建议始终人工审核。
- 文章不得诊断疾病、提供治疗方案、保证效果或替代医生意见。
- 资料没有提供的门店、价格、人物、资质、案例和效果数据不得补造。
