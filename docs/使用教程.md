# 一麦GSO双擎优化使用教程

## 安装

1. 在 WordPress 后台上传 `yimai-gso-optimizer-latest.zip`（或后台「在线更新」面板直接升级）。
2. 启用“一麦GSO双擎优化”。
3. 进入“一麦GSO双擎优化 > 基础设置”，配置 AI 平台、模型和 API Key。
4. 在“GEO实体”填写品牌主体信息，在“品牌资料”导入课程、服务和公开内容资料。

## 导入一麦资料

1. 打开“一麦GSO双擎优化 > 基础设置 > 品牌资料”。
2. 上传知识库 ZIP，或选择多个 Markdown、TXT、JSON、CSV、DOCX、PDF、XLSX 文件。
3. 等待本地解析和 AI 分类。
4. 查看资料范围：公开、内部参考、受限或已拦截。
5. 管理员复核后再将适合官网使用的资料设为“公开”。

已拦截资料只保留必要的识别记录，不保存正文，也不会参与文章生成。内部参考资料可帮助模型理解一麦业务，但提示词会明确禁止逐字公开。

## 自动更新博客

1. 打开“内容创作 > 自动发布”。
2. 设定每天运行时间、文章数量、分类、篇幅、配图数量和发布状态。
3. 可填写人工主题列表；留空时，系统会从已批准知识资料中选取主题种子。
4. 初次运行建议选择“草稿”，人工检查品牌事实、健康边界和排版。
5. 稳定后再切换为定时发布或直接发布。

## SEO 与 GEO

文章发布后可继续使用：

- SEO 标题、摘要、关键词和 canonical。
- H1-H3 结构、内链、图片 ALT 和内容新鲜度。
- Article、FAQ、Breadcrumb、LocalBusiness 等 Schema。
- Sitemap、llms.txt 和搜索引擎推送。
- GEO 可提取性、实体一致性、FAQ、引用与品牌可见度扫描。

GEO 扫描属于模型模拟结果，不等同于搜索平台的真实排名。新版扫描使用不带品牌暗示的中性问题，再检测回答是否自然提及一麦。

## 404 页面

「404 页面优化 → 自定义404页面」里可以改出一张与站点风格一致的 404 页。

1. 点「重新生成模板」把默认设计载入代码框；首次打开这一栏也会自动生成。
2. 「页面骨架」默认「跟随站点主题」：套用主题的页头页脚与字体，深浅色主题都不会突兀。不希望 404 页出现导航时，改成「独立页面」。
3. 「配色模式」控制独立页面的浅色/深色；「主色」勾选「自动跟随站点主题色」时会从主题调色板里取色，取消勾选后可手动指定。
4. 代码框可以直接改 HTML 与 CSS，右侧是实时预览。改完点「保存并启用」，前台 404 立即生效。
5. 「恢复默认模板」会清掉自定义代码并回到内置设计；「真实页面预览」用当前主题真实渲染，用来核对页头页脚是否协调。

代码框里保留几个占位符，保存后前台仍会按每次请求实时填充，不需要手工改列表：

- `<!--yimai-404:recent-posts-->` 最新文章列表项
- `<!--yimai-404:categories-->` 分类胶囊
- `<!--yimai-404:suggestions-->` 按请求路径智能匹配的文章推荐
- `<!--yimai-404:path-->` 当前请求路径

保存时会过滤 `<script>`、iframe、内联事件与 `javascript:` 协议，只保留排版与样式。

## 微信分享卡片

在微信里把官网链接发给客户或发朋友圈，默认只有一条裸链接。打开「微信分享卡片」面板并配置认证服务号后，分享出去的就是带封面、标题和描述的卡片。

1. 公众号后台「设置与开发 → 基本配置」拿到 AppID 与 AppSecret，填进面板。
2. 把「JS接口安全域名」验证文件的那串字符填进「公众号校验文件托管」，插件会直接提供 `/MP_verify_xxxx.txt`。
3. 在公众号后台把站点域名加进「JS接口安全域名」，把服务器出口 IP 加进「IP白名单」。
4. 上传一张分享封面图（JPG/PNG、≥ 500×500、英文文件名），点「测试公众号凭据」。
5. 手机微信打开文章页，点右上角「···」→ 发送给朋友确认卡片。

调试期可开「调试角标」，页面左下角会显示成功或失败原因，确认后关掉。抓取自检面板可以按微信 UA 抓任意页面并逐项打分。细节见 `docs/微信分享卡片-配置指南.md`。

## 安全边界

- 不要把会员身份、联系方式、体测、病史或私聊资料调整为公开。
- 孕产、疼痛、麻木、康复和药物内容建议始终人工审核。
- 文章不得诊断疾病、提供治疗方案、保证效果或替代医生意见。
- 资料没有提供的门店、价格、人物、资质、案例和效果数据不得补造。
