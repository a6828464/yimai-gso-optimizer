# 公众号同步 · 使用指南（2.13.0）

一句话：把 WordPress 里的文章（**已发布 / 草稿 / 待审**），按公众号排版重写一遍，送进**公众号草稿箱**。

**发布动作仍然由人来做——这个插件不会替你按下「群发」。**

---

## 一、这个功能做什么、不做什么

| 会做 | 不会做 |
| --- | --- |
| 本站文章（已发布 / 草稿 / 待审）→ 公众号草稿箱 | 不群发、不推送粉丝、不调发布接口 |
| 正文按公众号约束重排（标签白名单、样式内联） | 不改动你 WordPress 里的原文 |
| 正文图片转存到公众号素材（微信不显示外链图） | 不搬运视频、音频、iframe、表单 |
| 特色图自动裁成 900×383 当封面 | 不猜封面——没图就是失败，见「兜底封面」 |
| 外链转成文末脚注，正文里加 [1][2] 角标 | 脚注不做点击跳转（公众号正文点不动外链） |
| 标题 64 字、摘要 120 字超长自动截断 | 不做互斥锁之外的多站点协同 |

> 记住一句：**草稿箱是终点**。进草稿箱之后，排版、封面、摘要都还要人去公众号后台核对并手动发布。

---

## 二、发布后第一件事：真机验证清单

本次交付前只在离线桩里验证过（开发机没有 WordPress 站点、没有公众号 AppID），下面 6 件事**只有真机能证明**。第一篇文章进草稿箱后，请在公众号后台打开手机预览，逐项打勾：

- [ ] **标题、作者、摘要都进来了**——作者是同步设置里的「默认作者」（默认 `一麦瑜伽`），摘要没手写时自动取正文前 110 字
- [ ] **正文图片全部显示**——微信不显示外链图，任何一张没转存成功的图都会变成空白/裂图，这是最典型的失败
- [ ] **表格不错行、不溢出屏幕**——手机竖屏下表格**需要左右滑动才是正常**（不是故障），但不能被压成一行一个字；列宽够不够，看「错误原因」这类长文本是不是一行能读几个字
- [ ] **代码块能横向滚动，尖括号是原文**——`<div>` 要显示成 `<div>`，不能被当成标签吃掉
- [ ] **封面正常**——2.35:1（900×383）裁切后没有切掉人脸、logo 或标题文字
- [ ] **外链脚注对得上**——正文里的 [1][2] 角标出现，文末编号与角标一一对应

任何一项不通过：先看第六节「失败自助排查表」，再看第七节「手机预览排版 5 个必看点」。

## 三、开启步骤

1. **公众号侧前置**（一次性的，缺一项就全盘不通）
   - 公众号已认证（草稿箱接口对未认证主体直接 48001）
   - 拿到 AppID / AppSecret（公众号后台 → 设置与开发 → 基本配置）
   - 把**本站服务器的出口 IP** 加进同一个页面的「IP 白名单」
2. **填凭据**：`一麦GSO双擎优化 → 微信分享卡片 → 一号凭据`，填 AppID / AppSecret。
   同步功能**复用这份凭据**，不需要在同步页再填一次。填完可以点该页的「测试凭据」确认通。
3. **进同步页**：`一麦GSO双擎优化 → 公众号同步`。
4. **勾总开关**：「允许把文章同步进公众号草稿箱」。
   同时按需设置：默认作者、同步分类、兜底封面（见下节）。
5. **用真文章试一次**：点页头「立即同步最新一篇」，或到文章编辑页右侧「公众号同步」框点「立即同步」。
   成功后到公众号后台「草稿箱」核对，再手动发布。

> 总开关关掉后：不再自动入队，队列也停止出队；但**「立即同步」按钮仍然可用**——人工点的动作不该被开关拦住。

## 四、同步规则

**哪些文章会同步**

- **自动触发**只处理**已发布**（publish）的文章（首次发布那一刻入队）。草稿 / 待审不会自动入队，但可以在「从历史文章选择同步」里人工挑一篇（见第十一节）。私密、定时、回收站里的文章永远不入队。
- 「同步分类」是白名单：**全不选 = 所有分类都同步**；勾了父分类，子分类下的文章也算命中。
- 单篇可以在编辑页勾「不同步这篇文章」，随时取消勾选即恢复。勾上后：已在排队的任务会被置为「已跳过」，之后发布也不再自动入队；但手动点「立即同步」仍会执行——人工点的动作是明确意图，不会被这个勾拦下。

**什么时候触发**

- **首次发布时自动入队**（草稿→已发布的那一刻，受「发布后自动入队」开关控制）。
- **已发布文章的后续修改不会自动重排**——这是有意的：改个错别字不该每次都去调微信接口。要覆盖草稿请人工点「立即同步」。
- 队列每 5 分钟跑一轮，每轮最多 3 篇，单篇最长 120 秒——这是为了不把站点拖慢，也是为了让配额消耗可控。
- 想立刻要结果，就手动点「立即同步」。

**改过的文章会怎样**

- 内容没变：不会重复建草稿（幂等键是「文章 + 内容指纹」）。
- 改完点「立即同步」：**覆盖同一份草稿**，草稿箱里不会多出一篇。
- 如果你在公众号后台把这份草稿删了，下次重试会自动重建一份新的（插件认得 40007 并自愈）。

**几条硬上限（插件会先拦住，不会白跑一趟）**

| 项目 | 上限 | 超了怎么办 |
| --- | --- | --- |
| 标题 | 64 字（自动截断留省略号） | 一般无需处理 |
| 摘要 | 120 字（自动截断） | 一般无需处理 |
| 正文 | 20000 字 / 1MB | 拆成上下篇 |
| 正文图片 | 最多转存 20 张 | 删图或拆篇；超出部分会留外链（微信里显示空白） |
| 单张图片 | 上传前压到 900KB 以内 | 仍失败就换图 |
| 封面 | 必须有；无特色图则用「兜底封面」 | 设特色图或设兜底封面 |

## 五、状态怎么看

任务表里每一行都是「一篇文章的一次同步」，状态一共 6 个，运营日常只需要认前 3 个：

| 状态 | 徽标 | 含义 | 你该做什么 |
| --- | --- | --- | --- |
| 待处理 | 蓝 | 已入队，等下一轮（≤5 分钟） | 等；急就点「立即同步」 |
| 已进草稿箱 | 绿 | 草稿已建/已更新 | 去公众号后台核对排版，手动发布 |
| 失败 | 黄 | 这一轮失败，会自动重试 | 看「错误原因」列，对照第六节 |
| 已放弃 | 红 | 连续失败 5 次，不再自动跑 | 修好原因后点「重试」（次数会清零） |
| 已跳过 | 灰 | 勾了「不同步」导致排队任务被取消 / 文章被改回草稿或已删除 | 一般无需处理 |
| 处理中 | 蓝 | 正在提交 | 等十几秒刷新 |

编辑页右侧的「公众号同步」框里也能看到同一状态；勾「不同步这篇文章」后不会再有新任务。

## 六、失败自助排查表

先看任务表的「错误原因」列（编辑页侧栏可展开看完整 errmsg 与 errcode），再对号入座：

| 现象 / 错误码 | 原因 | 点哪里修 |
| --- | --- | --- |
| `40164` invalid ip | 服务器出口 IP 不在公众号 IP 白名单 | 错误信息里带着真实出口 IP，把它加进「公众号后台 → 设置与开发 → 基本配置 → IP 白名单」；站点换机房/IP 漂移要重新加 |
| `48001` api unauthorized | 公众号没有这个接口权限（主体未认证最常见） | 公众号后台完成主体认证；未认证主体的草稿箱接口不可用 |
| `45009` reach max api daily quota | 当天接口调用次数用尽 | 次日 0 点自动重置；当天减少批量同步，或到公众号后台申请提额 |
| `40009` image size out of limit | 单张图片超限（正文图 ≤1MB，封面永久素材 ≤2MB） | 换小一点的图；插件已自动压到 900KB，仍报错说明图片本身异常（超大尺寸/异常格式） |
| `40007` invalid media_id | 草稿或封面素材被人在公众号后台删了 | 直接点「重试」，插件会清掉坏 id 并自动重建 |
| `40001` / `42001` / `40014` token 相关 | access_token 被别处刷新或过期（同 AppID 有别的系统在刷） | 点同步页的「重试」；仍失败去「微信分享卡片」页点「清除缓存」再试 |
| `45003` / `45004` 标题/摘要超长 | 标题 >64 字或摘要 >120 字 | 插件已自动截断；若仍出现，检查是否手写了超长摘要 |
| `40013` / `40125` / `41004` 凭据错误 | AppID 格式不对 / AppSecret 无效或已重置 | 到「微信分享卡片 → 一号凭据」重填 AppSecret |
| `封面图本地文件不存在` | 特色图不是本地文件（站点接了 OSS/七牛/COS 之类的附件云存储） | 见第九节「已知限制」；临时办法是给这篇换一张本地图片 |
| `没有特色图片`（no_cover） | 文章没有特色图，且没设兜底封面 | 设特色图，或在同步设置里指定「兜底封面」 |
| `正文超过 20000 字` | 正文超长，微信会静默拒收 | 拆成上下篇 |
| `正文渲染结果为空` | 正文全是短代码/iframe/脚本，清洗后没剩下内容 | 检查该文正文是否只有嵌入块；补正文或不上公众号 |

修完不用等：在任务表点该行「重试」，或在编辑页点「立即同步」，立即生效。

## 七、手机预览排版 5 个必看点

进草稿箱后，在公众号后台点「预览」发到自己手机，按顺序看这 5 处：

1. **首屏三件套**：标题是否被截断得难看、作者是否对、摘要是否是想要的那句。
2. **图片**：从头滑到底，逐张看有没有空白/裂图——有空白就是那张图没转存成功（外链图微信不显示）。
3. **表格**：竖屏下表格**要左右滑动是预期行为**，第一次看到别以为坏了；只需确认两件事——表格没把整页撑破（页面本身不该左右晃）、长文本列（比如「错误原因」）不是一字一行。如果某列仍被挤成一字一行，说明这表列太多或某格塞了不可断的长串（超长 media_id、长英文 URL），建议拆表或改列表。
4. **代码块**：左右滑能看全；`<div>`、`<p>` 这类尖括号必须是原文，不能被当成标签吃掉。
5. **封面与脚注**：封面裁切有没有切掉人脸/logo；正文 [1][2] 角标与文末编号是否一一对应。

这 5 条都过了，再手动发布。**不要跳过第 2 条和第 3 条**——它们是最容易在电脑上看不出来、在手机上才暴露的问题。

## 八、失败后怎么手动重试

三个入口，效果一样：

1. **同步页任务表**：失败/已放弃的行右侧有「重试」。
2. **文章编辑页**右侧「公众号同步」框：点「立即同步」。
3. **同步页页头**：「立即同步最新一篇」（只对最新一篇，适合快速验证配置是否通）。

手动重试会把「尝试次数」清零，等于重新获得 5 次自动重试。若重试仍失败，说明根因没修（比如 IP 白名单还没加），先按第六节处理。

## 九、已知限制与技术债

### 已知限制（配置解决不了的，别在设置里找）

| 限制 | 说明 |
| --- | --- |
| 封面要求特色图片是**本地存储** | 后端读的是服务器本地文件路径。站点一旦启用 OSS / 七牛 / 腾讯云 COS 等附件云存储（uploads 搬到云上、本地只剩占位），封面会报「封面图本地文件不存在」。这需要插件改造，不是配置能解决的，已列入后续版本。 |
| 只到草稿箱，不自动群发 | 不含一键发布/批量勾选同步/阅读数回流。2.13.0 起可以逐篇挑历史文章同步（见第十一节），批量勾选仍不做——那会放大每日配额风险。要发布请到公众号后台手动操作。 |
| 依赖 WP-Cron | 队列靠 WP-Cron 驱动。低流量站点建议在服务器上配真实 cron 定时触发 `wp-cron.php`，否则会「看起来没在跑」。 |
| 公众号主体必须已认证 | 未认证主体调用草稿箱接口直接 48001，插件层面无法绕过。 |
| 有每日调用配额 | 批量同步会消耗配额，撞 45009 要等次日 0 点。 |
| 表格横滑不是万能兜底 | 手机端把表格整体撑到 ≥720px、靠横滑阅读，但**列宽仍由内容决定**：某个单元格若塞了不可断的长 token（超长 media_id、长英文 URL），表格会被撑到 1000px 以上，「错误原因」这类列又会掉回约 84px、变成一字一行。中文标题可以逐字换行，通常不触发；真遇到就拆表或把那串挪到正文。 |

### 技术债（本期已知、有意不修，写在这里免得下次重新排查）

| 项 | 现状与影响 | 计划 |
| --- | --- | --- |
| `admin.css:5319` 的 `.yimai-gso-layout > .yimai-gso-panel{width:100% !important}` | 该规则按 content-box 计算，导致面板比栅格宽 30px。本期用覆盖层治标（视觉已正常）。 | 2.10.x 直接改源样式，删掉覆盖层 |
| `class-admin.php` 里 10 张老表缺 `.yimai-gso-table-wrap` | 本期靠父容器横滑兜住，手机端可用，但表格没有独立横滑区域 | 下版逐个补包裹层 |
| `responsive.css` §7 的 `.ymwx-*` 补丁 | 页面已全部迁移到 `.yimai-gso-*`，PHP 里 `class="...ymwx..."` 计数为 0，属死代码 | 下版删除 |
| 6 条规则依赖 `[style*="..."]` 属性选择器 | 本期用来命中老页面的内联样式；一旦有人把内联样式改成类名，这些规则就失效，需要同步删掉 | 随老页面迁移一起清理 |
| 封面依赖 `get_attached_file()` | 见上面「已知限制」第一条，附件云存储站点会失败 | 下版改为优先 `wp_get_attachment_url()` + 下载兜底 |
| 分享页 enqueue 的 hook 匹配过宽 | `strpos($hook,'yimai-gso-wechat')` 会把 `wechat.css` 也加载到「公众号同步」页。实测 10KB、且该页不使用 `.ymwx-*` 类，无样式串味 | 技术债，不阻塞发布；下版改成精确匹配 hook 后缀 |
| 分享页「常见错误码」2 列表被撑到 720 | 该表自然宽度只有 319px，≤782 档跟随统一 `min-width` 到 720，多出约 160px 横滑。改 680 只能降到 361，既不解决窄表根因，又会让 6 列表的错误原因列重新贴近 130px 下限，故本期维持 720 | 已在 `docs/UI组件规范.md §2.7`「当前使用方」登记；下版按表分别设 `min-width` |

## 十、关掉这个功能

- **临时关**：同步页取消勾选「允许把文章同步进公众号草稿箱」并保存 → 不再自动入队、队列停止出队（手动「立即同步」仍可用）。
- **彻底关**：停用插件 → 本模块的定时任务会被清掉，不会留下永远失败的幽灵任务；队列数据表保留，重新启用后历史记录还在。

## 十一、从历史文章里挑一篇同步（2.13.0 新增）

同步页中部有「从历史文章选择同步」清单，不用再只靠页头那颗「立即同步最新一篇」。

- **能挑哪些**：已发布、草稿、待审三种状态。私密、定时、回收站里的文章既不出现在清单里，也不允许同步。
- **怎么挑**：默认列出最近 8 篇；可按标题/正文关键词搜索（回车即搜）、按状态筛选，还有「加载更多」。一篇一行，右侧「同步这一篇」。
- **草稿也能同步**：先把稿子写在 WordPress 里、直接推一份到公众号排版看效果，是常用做法。草稿被同步**不会**变成已发布文章，本站前台可见性完全不变。
- **草稿的「阅读原文」会留空**：草稿没有公开地址，`?p=ID` 那种预览链接对读者是登录页/404，所以微信侧不显示「阅读原文」；需要的话同步后到公众号后台补。
- **同一篇重复同步不会多一份**：幂等键仍是「文章 + 内容指纹」，改完再点「同步这一篇」是覆盖同一份草稿。
- **点完就地更新**：行内「公众号」列会立刻变成最新任务状态，不用整页刷新；要和下方「最近同步任务」表对照时，那一列是同一套状态。
- **不做批量勾选**：一次只能挑一篇。批量会放大 45009 每日配额风险，要成批同步请走「同步分类」白名单 + 自动同步。
